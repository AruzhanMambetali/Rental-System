# Kyz Uzatu — цифровая система аренды и продажи платьев

Учебный проект Full Stack (frontend, РК). React + Vite + React Router, данные — mock (`src/data.js`).

## Запуск
```
npm install
npm run dev
```
Откройте адрес из терминала (обычно http://localhost:5173).

## Демо-аккаунты (пароль 1234)
- Клиент: client@kyz.kz
- Менеджер: manager@kyz.kz
- Владелец: owner@kyz.kz

## Страницы
Главная `/`, Каталог `/catalog`, Вещь `/catalog/:id`, Оформление `/checkout/:id`, Мои заказы `/my-orders`, Вход `/login`, Регистрация `/register`, Менеджер `/manager`, Владелец `/admin`.

## Структура
- `src/components.jsx` — Navbar, Footer, Layout, ItemCard, StatusBadge, Calendar, Protected
- `src/pages.jsx` — страницы
- `src/store.jsx` — состояние, роли, проверка конфликта дат, статусы
- `src/data.js` — mock data
- `public/img` — фото платьев: `d1.jpg` — главное фото платья №1, `d1.1.jpg`, `d1.2.jpg` — другие ракурсы. Они подключены в `src/data.js` (поле `photos`, `tone` — цвет фона страницы, который меняется вместе с фото)

Менеджер и владелец добавляют, изменяют (данные, статус, фото) и удаляют платья во вкладке «Платья» своей панели.

Проект работает без backend; после перезагрузки страницы данные сбрасываются.

## Новое
- **QR-коды.** У каждого платья код `KU-<артикул>` (например KU-001). В панели менеджера/владельца: вкладка «QR-бирки» (печать) и «Сканер» (камера). Скан открывает `/scan/KU-001`: сотрудник меняет статус, клиент видит обычную карточку.
- **Чистка.** Между арендами одного платья блокируется 2 дня (`CLEAN` в `src/store.jsx`).
- **Предоплата.** 30% (`PREPAY`); менеджер отмечает «Предоплата получена».
- **WhatsApp.** Кнопки в заказах открывают чат с готовым текстом.
- **Язык.** Кнопка ҚАЗ/РУС в шапке; словарь в `src/i18n.jsx`. Панели сотрудников переведены частично.
- **Каталог.** Категории (по цвету) и сортировка.
- **Данные** сохраняются в браузере; сброс — «Сбросить демо-данные» в панели владельца.

Камера работает только на HTTPS или `localhost`: для проверки QR на телефоне выложите сайт (Vercel/Netlify; файлы `vercel.json` и `public/_redirects` уже есть).
